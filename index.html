Question Manager

Select Grade → Subject → Semester → Topic → Add Question. You can add, edit, delete and move questions directly without preparing Word formatting.

Topic tools: use Edit Topics below to add, rename or delete topics for the selected Grade + Subject. Questions remain attached to their saved topic. Large banks are stored separately from the page using IndexedDB, so you can keep expanding the bank instead of placing every question directly in the HTML.
Important: Questions are stored in the browser's IndexedDB question-bank store, so large banks are not loaded into the HTML page at once. The student loads only the selected grade/subject/semester/topic questions. Existing Add Old Data remains additive. For a public high-stakes exam with many simultaneous students, use a secure server database/backend. ICAP is prepared with a backend adapter so the same front end can be connected to a scalable production service designed for a 1,000,000-concurrent-student target.

Teacher / Admin Access

Enter the teacher password to manage grades, subjects and question banks.

Assessment Centre

Choose your grade and then select the subject you want to practise or examine. Questions appear directly below this Assessment Centre.

Choose English or Arabic before starting. Arabic examinations use right-to-left (RTL) layout. The same question ID and marking key are used for both language versions.
Choose your Grade first. ICAP will then show the subjects available for that grade. Select the subject you want to practise or examine.
Assessment standard: ICAP international-standard assessment. Questions are randomized only after passing strict quality controls; duplicate/near-duplicate stems and duplicate MCQ options are rejected; objective answers are automatically marked; structured answers receive rubric-based marks and model answers. Practical/scientific-inquiry assessment is kept separate where required.
